Install Media Bridge Helper

The Helper performs authorized downloads, stream merging, and audio conversion locally. Browser stores do not install native companion applications, so this one small Windows installation is required.

Install

  1. Install the extension from the supported browser store.
  2. Download and run the Helper installer.
  3. Restart the browser.
  4. Open Media Bridge and confirm that its status reads Ready.

No Python, PowerShell, FFmpeg, Deno, or administrator account is required.

Remove

Remove the extension from the browser, then uninstall Media Bridge Helper from Windows Installed apps. See the support guide for optional data cleanup.
