# Media Bridge public site template

Do not upload this directory directly: it contains release placeholders.

The public build must replace:

- `{{VERSION}}`
- `{{SUPPORT_EMAIL}}`
- `{{EDGE_STORE_URL}}`
- `{{INSTALLER_SHA256}}`
- `{{SIGNING_STATUS}}`

The built site must also contain the signed Helper installer, collected license
texts, and the exact FFmpeg corresponding-source archive linked from
`third-party.html`.
