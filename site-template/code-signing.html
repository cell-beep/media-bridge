Release integrity

Code-signing policy

Current status

Media Bridge is preparing an application for the SignPath Foundation open-source program. The current development installer is unsigned and is not offered here as a public production release.

After acceptance, signed release pages will state: Free code signing provided by SignPath.io, certificate by SignPath Foundation. Acceptance is not assumed or guaranteed.

Covered artifacts

Signing is limited to Media Bridge release artifacts built from tagged revisions of the public repository by the documented automated build. Private or locally modified binaries are not eligible.

Roles

  • Committer and reviewer: cell-beep.
  • Approver: cell-beep, acting for Soft Harbor Studio with multi-factor authentication enabled.

Every production signing request requires manual approval.

Release requirements

  1. Automated tests and extension lint must pass.
  2. Dependency versions, notices, required source, checksums, and an SBOM must accompany the release.
  3. The installer must originate from a tagged public commit and pass clean-machine testing.
  4. Signing keys and credentials must never be stored in the source repository.

Privacy statement

Media Bridge will not transfer information to other networked systems unless specifically requested by the user operating it. A download request connects the local Helper to the media URL selected by the user. Media is not uploaded to a Media Bridge cloud service. See the privacy policy.
