Support

Email {{SUPPORT_EMAIL}}. Do not send passwords, browser cookies, private media URLs, or copyrighted files.

Helper shows Offline

  1. Confirm that Media Bridge Helper is listed in Windows Installed apps.
  2. Fully close and reopen the browser.
  3. If needed, reinstall the current Helper from the official download page.

A site returns HTTP 403

A website can reject a particular stream even when other items work. Remove any partial file for that item and try an available lower quality. Do not repeatedly retry content that requires authorization you do not have.

Downloads and local state

Files are saved to %USERPROFILE%\Downloads\MediaBridge. Small job-status records are stored under %LOCALAPPDATA%\Media Bridge\jobs.

Uninstall

  1. Remove Media Bridge from the browser's extension manager.
  2. Uninstall Media Bridge Helper from Windows Installed apps.
  3. Optionally delete %LOCALAPPDATA%\Media Bridge and downloaded files.
