Privacy Policy

Media Bridge processes authorized media downloads on the user's Windows computer. Version {{VERSION}} has no publisher analytics, behavioral advertising, account system, or cloud media processing.

Information processed

When the user opens Media Bridge, the extension can read the active tab URL and place it in an editable field. The extension sends the submitted URL, returned title, duration and thumbnail, format and quality choices, download action, local progress, and errors through Native Messaging to the locally installed Helper for the requested operation.

Mozilla classifies this local transfer as data transmission outside the extension. Soft Harbor Studio does not receive this information. Media Bridge does not access browser cookies, passwords, payment information, or general browsing history.

Network communication

The Helper connects directly to the submitted website and its associated content-delivery services. Those services receive ordinary network information, including the user's IP address, under their own privacy policies. Media files are not routed through Soft Harbor Studio servers.

Local storage and retention

Preferences remain in local browser-extension storage. Small download-job records remain under %LOCALAPPDATA%\Media Bridge\jobs. Completed files are saved under %USERPROFILE%\Downloads\MediaBridge by default. Soft Harbor Studio does not receive or retain these records.

Sharing and sale

Soft Harbor Studio does not sell locally processed URLs, media metadata, job records, or files and does not share them with advertisers or data brokers.

User controls

Users can edit or clear a URL before inspection, remove downloaded files, uninstall the extension and Helper, and delete remaining local Media Bridge data.

Security

The extension communicates with the installed Helper through browser Native Messaging. The Helper rejects credential-bearing URLs and local or private-network destinations.
