# Security Policy

## Reporting a vulnerability

Please do not publish a suspected vulnerability in a public issue before it is
triaged. Report it to `chatandworkv@gmail.com` with:

- the affected Media Bridge version;
- reproduction steps;
- expected and observed behavior;
- the security or privacy impact;
- any suggested mitigation.

Do not include real credentials, private media, or personal browser data. You
should receive an acknowledgement within seven days. After a fix is available,
the project may publish a coordinated advisory and credit the reporter if they
want to be named.

Only the latest published version is expected to receive security fixes during
the current early-release phase.
